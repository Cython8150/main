## 终章补遗 C-1 仿真实验中的时间基准与“步”的测量

在步进仿真中，时间不是墙钟时间，而是“仿真时间步”的累加。每一个 `sim.step()` 将内部物理与传感器更新推进一步，其对应的真实时间长度由仿真时间步长设置决定。若将步进次数与某段控制循环绑定，可估计该段在仿真时间尺度的持续长度。对于差分雅可比，若每列需要 `fd_settle_max_steps` 次步进，六列共六轮差分，再加上主迭代的 settle 与多次迭代，单点到达的仿真步数可能非常可观。论文在“计算效率”或“实时性”讨论中，应说明实验是在何种 CPU 上测得的墙钟时间，并说明步进模式与实时模式的差异。若仅报告“平均十秒完成一次抓取”，而不说明机器配置与是否开启 GUI 显示，则结果不可比。另需指出：在弱算力机器上，OpenCV 的 `imshow` 会占用主循环时间，使墙钟时间被人为拉长，这属于实验环境记录必须覆盖的内容。

## 终章补遗 C-2 关于“成功”判据的形式化

主程序在若干位置以布尔返回值表示子任务是否成功，例如 `moveTipPositionPbvsDls` 返回真表示位置误差低于阈值。整轮任务成功应定义为：视觉有效、接近成功、抓取段成功、回零不发散、释放段（若平面存在）成功。建议在论文中给出一张逻辑与门表，把“部分成功”情况单独统计，例如“抓取成功但释放失败”。这将比单一成功率更能揭示模块瓶颈。若未来加入日志枚举错误码，可把统计自动化。

## 终章补遗 C-3 图像分辨率与视场、深度的耦合

分辨率提高带来细节，但也增加计算与传输开销，同时减小单像素对应的立体角，若光照不足噪声可能上升。深度缓冲若与 RGB 分辨率不一致，必须显式对齐或降采样到同一网格；本文假设一致并用同一索引取深度。若改为更高分辨率，需同步更新共享缓冲长度与索引公式，并重新评估 `medianBlur` 核大小与轮廓面积阈值。

## 终章补遗 C-4 机械臂奇异位形的几何直觉（肘部与腕部）

六自由度臂在某些构型下会出现肘部奇异或腕部奇异等典型现象，表现为某些方向上微小关节速度无法产生末端线速度，或出现多余自运动。数值雅可比在这些方向上得到极小奇异值，DLS 通过阻尼抑制关节速度爆炸，但末端任务误差在该方向上仍难快速消除。释放阶段采用更高接近点再下降，是一种避开“水平远伸 + 低阻尼”组合诱发振荡的策略。论文可用示意图展示 UR5 在场景中的典型姿态，帮助读者建立直觉。

## 终章补遗 C-5 课题与课程设计的区别说明

课程设计往往以功能点打分，毕业论文还要求问题表述、方法对比、实验设计与结论边界。本文素材同时覆盖功能实现与一定理论叙述，但若要完全符合毕业论文规范，还需补充：完整摘要与关键词、规范的图表编号、足够数量的参考文献、指导教师评审意见与签字页等行政管理材料。技术内容之外，格式规范常常决定形式审查是否通过。

## 终章补遗 C-6 代码风格的可变性与一致性

仓库中混用 `cout` 与 `printf`，混用 `std::vector` 与 `vector`，在大型工程中可能需要统一。但在本科单人项目中，一致性规则可由指导教师放宽。更重要的是错误路径处理：线程是否正确停止、仿真是否停止、返回值是否表明失败原因。论文可在“软件质量保证”里列举这些实践。

## 终章补遗 C-7 机器人操作系统 ROS 与本项目的对照

ROS 提供节点、话题、服务与 TF 坐标变换框架，MoveIt 提供运动规划。本项目直接在 C++ 中调用 Coppelia API，不属于 ROS 生态。若迁移 ROS，可将视觉作为节点发布 `sensor_msgs/Image`，将控制作为节点订阅关节指令；代价是学习曲线与系统复杂度上升。论文中对 ROS 的讨论应保持中性：说明适用边界即可。

## 终章补遗 C-8 许可、著作权与第三方素材

若论文插入 Coppelia 场景截图、开源图标或他人论文插图，应确认许可。一般来说，自己仿真截图属于作者产出；引用他人曲线图需注明来源。字体与学校模板通常由教务处统一规定。

## 终章补遗 C-9 量化评估指标的构造建议

除成功率外，可定义位置误差 RMSE、迭代次数均值与方差、任务用时均值与方差、关节速度峰值等。若缺乏真值，可用仿真地面真值（物体位姿）作为参考。注意仿真真值与视觉估计之间的差别正是“感知误差”度量来源。

## 终章补遗 C-10 失败案例库的价值

把典型失败保存为案例：掩膜破碎、深度飞点、PBVS 不收敛、物体穿透桌面、夹爪未闭合。每个案例配截图与日志片段，在论文“讨论”中占用一页左右，不仅增加篇幅，也显著提高说服力。评委往往更信服“我知道为何失败”而非“我一直成功”。

## 终章补遗 C-11 远程连接与网络延迟对 API 的影响

若 CoppeliaSim 运行于远程主机，ZeroMQ 往返延迟将叠加到每次远程调用。差分雅可比对延迟极其敏感，因为差分需要大量调用。此时应尽量本地运行仿真，或优化网络与减少不必要调用。论文实验环境应写明本地或远程。

## 终章补遗 C-12 线程优先级与操作系统调度（概念）

在 Linux 上可用调度策略与优先级微调线程，但过度实时需要内核补丁或实时扩展。本科项目通常不触碰该层。若视觉线程饥饿导致深度长期不更新，主线程可能在 `wait` 阻塞；可通过超时机制缓解。

教材、公开课与开源示例 plentiful；关键是选择与 Coppelia 场景一致的坐标约定。阅读英文文献时注意 quaternion 顺序与右手系定义，不同论文符号冲突频繁。

## 终章补遗 C-21 再论深度噪声：统计滤波如何写进论文

对掩膜内深度值排序取中值，或对有效像素做双阈值截断，可减少飞点影响。实现上需额外遍历像素并处理边界；论文可描述复杂度与收益。

## 终章补遗 C-22 再论夹爪：力位混合控制的缺席

真实夹爪可能具备力位混合或电流环控制；仿真中以力与速度目标近似。若论文涉及“抓取可靠性”，应声明未建模接触力，可用文献引用弥补。

## 终章补遗 C-23 再论立方体质量与摩擦：释放后下落姿态

质量与摩擦系数影响滑动与倾倒；本文设置质量并让步进下落，但不测量落点分布。若要实验数据，应添加地面标记与位姿记录。

## 终章补遗 C-24 再论无限循环 `for(;;)` 的工程风险

主程序为无限循环，适合演示；若用于自动测试需加最大轮次或终止条件，否则 CI 无法结束。论文可说明“演示模式”与“测试模式”的差异。
