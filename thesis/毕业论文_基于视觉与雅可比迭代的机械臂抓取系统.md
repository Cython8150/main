# 基于视觉伺服与数值雅可比的机械臂目标抓取系统设计与实现

**（学位论文稿 · 与仓库 `undergraduate_thesis` 实现一致）**

---

## 摘要

针对六自由度工业机械臂在非结构化或半结构化场景中对色块目标进行定位、接近、抓取与分类放置的需求，本文在 CoppeliaSim 机器人仿真平台中搭建 UR5 与 RG2 二指夹爪的联合场景，采用基于 ZeroMQ 的 C++ 远程 API 客户端，与 OpenCV 视觉处理、手眼标定结果以及阻尼最小二乘（Damped Least Squares, DLS）意义下的位置基视觉伺服（Position-Based Visual Servoing, PBVS）相结合，实现从视觉感知到关节空间运动闭环的完整抓取流程。系统通过独立线程持续获取视觉传感器 RGB 与深度缓存，在基座坐标系下对目标三维位置进行估计；在控制层不依赖显式运动学链求导，而利用仿真中关节微扰的数值差分估计位置雅可比，并在每次迭代中解算关节增量，使末端执行器以可控步长趋近目标。主程序在每一轮任务中随机生成立方体位姿与颜色，完成“检测—接近—闭合—抬升/回零—按颜色释放在对应平面”的循环，并处理父子关系、刚体属性与步进仿真等工程细节。实验与调参部分结合位置容差、阻尼系数、远距增益等参数，分析收敛性、奇异性与物理引擎下的稳定性。结果表明，所提软件架构能够支撑可复现的仿真实验，为后续实机迁移与算法对比提供基线。本文最后总结实现经验，并讨论视觉深度噪声、标定残差与雅可比数值噪声对精度的影响及改进方向。

**关键词：** 机器视觉；手眼标定；位置基视觉伺服；阻尼最小二乘；数值雅可比；CoppeliaSim；UR5；远程 API

## 第一章 绪论

### 1.1 研究背景与意义

随着仓储分拣、柔性制造与实验室自动化等应用的发展，机械臂在“看见—决策—操作”闭环中的能力成为关键指标。传统示教或关节空间轨迹规划难以适应目标位姿与类别不断变化的场景，而视觉反馈可将任务空间误差显式引入控制律，使末端执行器向图像或三维空间中的期望状态收敛。对于学历本科阶段在有限硬件条件下开展研究，高保真仿真平台能够降低安全与成本风险，并允许在可重复条件下比较不同视觉算法与控制策略。

CoppeliaSim（原 V-REP）提供多种物理引擎、丰富的传感器模型与远程 API，适合作为视觉—控制联合系统的试验场。工程上，从视觉传感器获得的是二维图像与（可选的）逐像素距离信息，需经相机内参、深度反投影与手眼关系，将点从相机系或图像系转换到机械臂基座系，才能与逆运动学或雅可比型控制律对接。本课题程序以 C++ 实现，强调与仿真步进、共享内存式图像缓存、互斥与条件变量同步，是在“真实系统约束”下组织多线程软件的一次综合训练。

### 1.2 研究目标与任务分解

结合仓库中 `testGrab.cpp` 主流程与 `visual_module`、`jacobian_cartesian_control`、`control` 等模块，本工作的直接目标可概括为：

1. 在仿真中稳定获取固定于场景中的视觉传感器输出，并避免多线程同时调用同一传感器句柄造成竞态。
2. 对红、绿、蓝三类纯色立方体进行颜色分割，结合深度缓冲实现单目结构光式（或仿真深度）三维定位，并变换到基座系。
3. 以 PBVS 方式控制指尖位置，分阶段完成接近、下降抓取、带载回“家”与在指定色区释放；释放后恢复物体为动力学体并步进仿真以观察下落行为。

更宏观上，本文希望形成一条可复现的“从标定数据文件到可运行可执行文件”的完整链条，为论文撰写提供与代码一一对应的说明材料。

### 1.3 主要贡献与论文结构

本文的贡献侧重工程系统层面：一是给出与 CoppeliaSim 步进模式配合的雅可比—DLS 迭代式 PBVS 实现细节，包括差分步长、关节到位判据与远距误差增益；二是对眼在手外标定结果 `T_base_from_cam` 与反投影几何之间坐标系一致性的处理（含对 `detectObject3D` 中 x、y 取反与标准 OpenCV 相机系之间的显式桥接）；三是主任务循环中关于随机立方体创建、颜色指定、夹爪力/速度、父子链接与物理参数切换的完整流程说明。

后文结构安排如下：第二章回顾视觉伺服、手眼标定与机器人微分运动学基础；第三章描述系统总体架构与通信方式；第四章详述视觉处理与几何变换；第五章介绍控制与雅可比数值解算；第六章对主程序任务状态机与参数进行逐段解读；第七章讨论标定与实验；第八章为结果与讨论；第九章总结与展望。附录中给出关键符号、参数表与算法描述，便于与源码对照。

## 第二章 相关技术与理论基础

### 2.1 单目与 RGB-D 视觉中的目标定位

在仅使用单目灰度或彩色图像时，目标的三维位置具有尺度不确定性，需要额外约束（已知模型、地面约束、多视图或固定基线双目）。本项目中，视觉传感器除 RGB 外还提供了与像素对齐的深度缓冲，因而可在内参已标定条件下，对像素 \((u,v)\) 与深度 \(Z\) 做反投影：

\[
X = (u - c_x)\,Z / f_x,\quad
Y = (v - c_y)\,Z / f_y
\]

（实现中根据 CoppeliaSim 与 OpenCV 相机轴向约定，对 \(X,Y\) 的符号与后续基座变换做统一。）内参与畸变从 `calibration_results/cameraParaments.xml` 读取，与 `visual_module.cpp` 中 `detectObject3D` 一致。深度可叠加小常数 `depth_offset` 以补偿标定面与仿真深度定义之间的系统偏差，该偏置与“三者同加”的约定在代码注释中已说明，避免 x、y、z 使用不一致深度导致的几何不一致。

### 2.2 手眼标定与坐标变换链

手眼问题分为眼在手上（eye-in-hand）与眼在手外（eye-to-hand）。标定求取相机与末端或基座之间的固定刚体变换，常用 AX=XB 或类似形式的闭合链求解。本仓库中 `point_cam2base` 从 `hand_eye_eye_to_hand_result.xml` 读取 `T_base_from_cam`，将 OpenCV 相机坐标系下的齐次点 \( \mathbf{p}_c \) 映射到基座系 \( \mathbf{p}_b = \mathbf{T}_{b\leftarrow c}\,\mathbf{p}_c \)。由于 `detectObject3D` 为对齐 CoppeliaSim 视觉系对 x、y 做了取反，在乘手眼矩阵之前需要回到 OpenCV 约定：代码将输入点的 x、y 分量取反后再构造四维向量，这一环节是与标定脚本 `eye_in_hand_calibration.cpp` / `to_hand_calibration.cpp` 配合的必要约定，任何一侧单方面改动都会导致系统性偏差。

### 2.3 视觉伺服简述：IBVS 与 PBVS

视觉伺服按误差定义可分为基于图像的 IBVS 与基于位置的 PBVS。IBVS 在图像平面定义特征误差，对未知三维结构有时更具鲁棒性，但对奇异与相机退化敏感；PBVS 在任务空间（常用笛卡尔位姿）定义误差，需要三维估计或位姿解算，但直观且易于与只关心位置的抓取任务结合。本文实现采用 PBVS 思想中的“仅位置”部分：期望量为指尖在基座系下的三维坐标，反馈由仿真 `sim.getObjectPose(tip, base)` 获得，视觉用于生成抓取与接近路标，而非每步闭环图像特征。

### 2.4 微分运动学与雅可比

对串联机械臂，末端线速度与关节速度满足 \( \mathbf{v} = \mathbf{J}(\mathbf{q})\dot{\mathbf{q}} \)。数值上可用有限差分近似位置雅可比：

\[
\mathbf{J}_{p,i} \approx \frac{\mathbf{p}(q + \delta_i \mathbf{e}_i) - \mathbf{p}(q)}{\delta}
\]

其中 \( \mathbf{p} \) 为指尖位置，\( \delta_i \mathbf{e}_i \) 为第 \(i\) 个关节增量。该方法不依赖显式 DH 参数或符号推导，在仿真环境中可直接利用 `setJointTargetPosition` 与 `step` 带来的内置动力学与控制器跟踪，获得“仿真一致”的雅可比，代价是差分噪声与计算量。

### 2.5 阻尼最小二乘逆解

对欠定或接近奇异构型，普通伪逆会放大关节速度。阻尼最小二乘目标可写为最小化 \( \|\mathbf{J}\Delta\mathbf{q} - \mathbf{e}\|^2 + \lambda^2 \|\Delta\mathbf{q}\|^2 \)，得到

\[
\Delta\mathbf{q} = \mathbf{J}^\top (\mathbf{J}\mathbf{J}^\top + \lambda^2 \mathbf{I})^{-1} \mathbf{e}
\]

其中 \( \mathbf{e} \) 为位置误差向量（期望减当前）。实现中 `dlsStep` 构造 \(3\times 6\) 的 \( \mathbf{J} \)，计算 \(3\times 3\) 矩阵求逆，再右乘误差，与教材及 Sciavicco–Siciliano 等经典表述一致。参数 `damping_lambda` 增大可抑制振荡但在误差朝零方向上变慢，需要在仿真步长与关节最大增量约束下折中。

## 第三章 系统总体设计

### 3.1 软件栈与构建

工程基于 CMake，`CMakeLists.txt` 依赖 CoppeliaSim 头与 Python 工具链生成/校验远程 API 封装；可执行文件链接静态库 `RemoteAPIClient`、OpenCV 与线程库。环境变量 `COPPELIASIM_ROOT_DIR` 指向安装根目录以便 `find_package(CoppeliaSim)`。生成代码选项 `GENERATE` 可关闭，此时使用仓库内已提交的模板生成文件，便于离线构建。

### 3.2 远程 API 与仿真步进

主程序 `sim.startSimulation()` 后 `sim.setStepping(true)`，所有动力学与传感器更新在显式 `sim.step()` 下前进，便于与雅可比差分、关节到位等待循环严格同步。多个 `RemoteAPIClient` 实例分别绑定主控与视觉侧连接：主实例驱动机械臂与物体，视觉实例重复获取同一场景中的 vision sensor 图像——这种拆分在某些部署方式下可隔离阻塞；同时也需注意多连接下仿真仍为一个实例，传感器访问须互斥（见下节）。

### 3.3 多线程视觉架构

`start_vision_thread_rgb` 与 `start_vision_thread_depth` 分别启动显示与缓冲线程。共享变量 `shared_rgb_image`、`shared_depth_buffer` 及若干 atomic 标志协调生命周期。对传感器的互斥由 `visionSensorMutex` 与 `rgb_requested` / `depth_requested` 及条件变量实现：`get_rgb_picture` 在深度请求未结束时等待，`get_depth_picture` 在 RGB 请求未结束时等待，避免并发 `getVisionSensorImg` 与 `getVisionSensorDepth` 交错导致未定义行为。

主线程在需要检测时调用 `get_share_rgb_picture` 读取缓存，并在 `detectObject3D` 内部等待 `depth_data_ready`，随后按中心像素索引访问 `shared_depth_buffer`。索引公式 `(511 - center_y) * 512 + center_x` 与图像竖直翻转 `cv::flip(..., 0)` 及分辨率约定一致，是视觉链路易错环节之一。

### 3.4 模块划分

- `find_handle.cpp`：解析场景中 UR5 六关节与 RG2 关节句柄。
- `visual_module.cpp`：图像获取、颜色分割、轮廓与矩心、深度反投影、手眼变换、线程入口。
- `jacobian_cartesian_control.cpp`：`moveTipPositionPbvsDls` 主循环与雅可比差分。
- `control.cpp`：`ur5_control`、`ur5_moveToJointTargetSmooth`（分段线性插值关节目标）、`rg2_control`（力与速度模式）。
- `testGrab.cpp`：高层任务逻辑与常量参数。

该划分使视觉、控制与任务编排解耦，便于单元替换（例如将颜色阈值改为学习分割网络）。

## 第四章 视觉处理与几何细节

### 4.1 颜色分割与通道歧义

工业彩色立方体在仿真中被赋予接近饱和的 RGB。`buildTargetCubeMaskRgb` 对红、蓝通道采用“RGB 顺序掩码 OR BGR 顺序掩码”的策略，以应对 Coppelia 缓冲与 `cvtColor` 可能引入的通道顺序不确定性；绿色通道位于中间，顺序混淆影响较小，故单次 `inRange` 即可。阈值区间 `lo_main=110` 与 `hi_other=130` 体现对背景与噪声的抑制，随后 `medianBlur` 去椒盐噪声，`findContours` 取最大连通域面积过滤小斑块。

### 4.2 轮廓矩心与深度采样

最大轮廓的图像矩给出质心像素；若零阶矩过小则返回无效点 `(-1,-1,-1)`。深度值在互斥保护下读取；面积阈值 `max_area < 100` 防止噪声点。应当指出，单点深度对透明、反光或边缘跳变敏感，更稳健的做法是对掩膜区域内深度做中值或截尾均值，本项目为简洁采用单点采样，论文实验中可记录由此引入的方差。

### 4.3 深度偏置与尺度

`depth_offset` 为经验常数，用于把仿真深度与棋盘标定或物体表面含义对齐。若偏置与手眼外参联合不当，反投影点会在相机射线方向上整体偏移，表现为抓取高度系统误差；主程序通过 `kMaxDescendFromHover` 限制相对悬停高度的最大下降量，从任务层避免穿透桌面。

### 4.4 眼在手外变换应用

`point_cam2base` 静态加载 `T_base_from_cam`，失败时返回无效点。齐次坐标下完成线性变换。此处与 `detectObject3D` 的坐标约定衔接已在第二节说明，是全文一致性关键点。

## 第五章 控制律与数值实现

### 5.1 关节目标与到位判据

雅可比迭代每一步：`setJointTargetPosition` 下发六个关节目标后，`settleArmToTargets` 循环 `sim.step()`，直至各关节当前位置与目标差小于 `settle_tol_rad` 或达到 `settle_max_steps`。差分雅可比使用更松的 `fd_settle_tol_rad` 与更少的 `fd_settle_max_steps` 以节省时间，依赖 DLS 阻尼吸收残差噪声。

### 5.2 误差与收敛判据

位置误差欧氏范数小于 `position_tol_m` 则成功返回。未收敛则在最大迭代次数后失败，主程序打印诊断信息。释放阶段使用单独的 `JacobianPbvsParams`：更大的 `position_tol_m`、`max_iterations`、`damping_lambda` 与略小的 `max_joint_step_rad`，配合两段式“先高后低”的竖直接近，减轻远处奇异附近的振荡。

### 5.3 远距增益与步长裁剪

当误差大于 `err_near_m`，对 Δq 乘以 `gain = min(gain_far_max, err/err_ref_m)`，使远距更快逼近；接近目标时增益回到 1。向量 Δq 还经 `clipVectorL2` 限制范数不超过 `max_joint_step_rad`，防止单步过大穿过奇异或激发仿真不稳定。

### 5.4 平滑回零

带载运动若瞬时给出关节目标，易在 Bullet 下引起大幅摆动。`ur5_moveToJointTargetSmooth` 在当前角与目标角之间做 `segments` 段线性插值，每段执行 `steps_per_segment` 次 `sim.step()`，从而平滑加载轨迹。与 `kHomeJointRad` 配合使用；注释提醒全零构型可能非稳定裕度姿态，需按场景改为合适“家”位。

## 第六章 主任务流程解析（`testGrab.cpp`）

### 6.1 初始化阶段

连接仿真、查找关节与指尖 `attachPoint`、启动视觉线程、初始化 PBVS 默认参数与 home 关节向量。

### 6.2 随机立方体生成

循环开头移除上一轮立方体；用均匀分布随机平面位置与颜色索引；`createPrimitiveShape` 创建立方体，设置父对象为世界、位姿与颜色，设为静态可响应以便抓取前稳定；短暂 `step` 让状态落稳。

### 6.3 张开夹爪与稳定

`rg2_control` 以指定力与速度打开；再步进并短暂休眠，等待振动衰减。

### 6.4 视觉检测与有效性

读取共享 RGB，`detectObject3D` 与 `point_cam2base`。失败则清理线程并退出。保存图像 `1.jpg` 便于事后检查。

### 6.5 接近与抓取 PBVS

在目标上方 `kApproachOffsetZ` 处首先收敛；读取接近后实际指尖高度 `z_hover`，按 `max(gz, z_hover - kMaxDescendFromHover)` 与可选 `kMinTipZBase` 计算实际抓取 z，防止视觉 z 过深。闭合夹爪参数；`setObjectParent` 将物体附着到指尖；再步进等待。

### 6.6 再次视觉（验证）

保存 `2.jpg`，打印抓取后中心（可选用于验证跟踪）。

### 6.7 带载回零

再次闭合夹爪并步进；`ur5_moveToJointTargetSmooth` 回 home；步进等待。

### 6.8 按颜色释放

根据颜色选择 `/Plane[0|1|2]` 路径读平面位姿，计算释放高度与更高的接近高度，两次 `moveTipPositionPbvsDls`。成功后：解除父子、关闭 static、设置质量、重置动力学、打开夹爪并步进模拟下落。

### 6.9 收尾与循环

回 home、移除物体、步进。无限循环直至外部终止（代码层面为死循环，实际运行依赖用户停止仿真）。

## 第八章 结果与讨论

### 8.1 收敛与参数敏感性

`damping_lambda` 过小易出现末端振荡；过大则收敛慢。`position_tol_m` 必须与仿真时间步、关节 PD 跟踪能力匹配——过严可能永远达不到而误判失败。释放阶段放宽容差是实用技巧，与注释中“z 差毫米级徘徊”现象对应。

### 8.2 数值雅可比噪声

差分步长 `fd_delta_rad` 需在截断误差与微分线性之间权衡；过小则差分不稳定，过大则线性近似失效。可通过自适应步长或两次中心差分改善，但会增加仿真步数。

### 8.3 多线程与实时性

视觉显示线程的帧率与主线程 PBVS 迭代竞争 CPU；在弱算力机器上可关闭 `imshow` 或降低刷新率。互斥锁在高频 `step` 下也可能引入抖动，更彻底的方案是使用无锁环形缓冲或单线程顺序采集。

### 8.4 迁移到实机的差距

实机存在相机延迟、标定漂移、关节柔性、抓取摩擦与碰撞模型差异；仿真中 `setObjectParent` 的刚性附着可掩盖接触力学复杂性。后续可引入力传感或触觉，替换为阻抗控制堆叠在 PBVS 外层。

算法 moveTipPositionPbvsDls
